### 2.Slack チャンネルで GitHub を連携登録するコマンド

#### 前提：

* Slack に GitHub アプリをインストール済み
* GitHub に Slack 通知を送るための連携設定済み（OAuth連携）

#### チャンネルに連携リポジトリを登録するコマンド：

```bash
/github subscribe owner/repo issues pulls commits
```

#### 解除：

```bash
/github unsubscribe owner/repo
```

### 3. `git-filter-repo`

`git-filter-repo` は \[`git filter-branch`] や \[`BFG Repo-Cleaner`] の高速・安全な後継ツールです。

特定ディレクトリだけを抽出して新リポジトリ化したい場合、コミット履歴から機密ファイルを完全に除去したい場合、メールアドレス・名前の一括変換（匿名化）したい場合などに使用します。

#### 特定のディレクトリを抽出

```bash
git clone --no-local --mirror https://github.com/owner/repo.git
cd repo.git

git filter-repo --subdirectory-filter src
```

#### ファイル除去

```bash
git filter-repo --path secrets.env --invert-paths
```

バックアップを取ることを忘れないようにします。

### 4. Git でワークツリーに別リポジトリを含める方法

#### サブモジュール（公式・一般的）

```bash
git submodule add https://github.com/owner/other-repo.git external/other-repo
```

* 外部リポジトリを自分のリポジトリの下に「リンク」する
* バージョン固定（コミット単位）できる
* `git clone --recurse-submodules` が必要

#### ワークツリー＋外部管理（高度）

`git worktree`は同じリポジトリの別ブランチを別のフォルダに展開する機能です。

例：

```bash
git worktree add ../build-dir build-branch
```

同一リポジトリの別ブランチを別ディレクトリに展開する仕組みです。

### 5. Git LFS（Large File Storage）

Git で扱いにくい大容量ファイル（画像、動画、バイナリなど）を効率的に管理する仕組みです。

#### セットアップ手順：

1. LFS をインストール

```bash
git lfs install
```

2. 追跡するファイルタイプを指定

```bash
git lfs track "*.psd"
echo "*.psd" >> .gitattributes
```

3. 通常通りコミット・Push

```bash
git add file.psd
git commit -m "Add large PSD"
git push origin main
```

`.gitattributes` に LFS の追跡対象が記録され、push 時に実体は Git LFS サーバーへ送信されるようになります。大容量のファイルを効率的に扱うことができるようになりますが、ストレージに制限があるので注意が必要です。GitHub, GitLab, Bitbucket などで対応しています。
